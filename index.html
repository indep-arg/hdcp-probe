hdcp-probe

Checks whether HDCP actually works between your GPU and your display. Use a normal window (not InPrivate/Incognito). On Windows, Edge is the only browser with hardware PlayReady, which is what streaming services use for 1080p and 4K.

1. Policy query

Asks each DRM system which HDCP version it could enforce right now. Fast, but it is a hypothetical question and some CDMs answer it badly.

2. Real license test (PlayReady)

Plays a protected clip from Microsoft's public PlayReady test server three times: without restrictions (control), requiring HDCP, and requiring HDCP 2.2. If the clip plays with the license that requires HDCP, HDCP works. This is the same check a streaming service does. Edge on Windows only. Keep this tab visible while it runs.
